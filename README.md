# AI Development Capstone

An end-to-end capstone project demonstrating professional software development with AI-assisted workflows — from planning and implementation to version control, documentation, and deployment readiness.

## About

This repository hosts the source code and documentation for an AI-powered Node.js application developed as part of an **AI Development Capstone** course. The project applies modern AI tooling to accelerate development while maintaining production-quality practices: structured code, conventional commits, clear documentation, and collaborative Git workflows on GitHub.

**Primary development environment:** [Cursor](https://cursor.com/)

## Learning Objectives

| Goal | Description |
|------|-------------|
| **Application development** | Design and implement a functional AI-driven application with Node.js |
| **AI-assisted workflows** | Use AI tools to accelerate coding, debugging, and documentation |
| **Version control** | Apply professional Git practices and GitHub collaboration patterns |
| **Maintainability** | Organize the codebase for clarity, testability, and future extension |
| **Documentation** | Record architecture decisions, setup steps, and usage instructions |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- [Git](https://git-scm.com/)
- A [GitHub](https://github.com/) account (for collaboration and remote workflows)

### Installation

Once the application scaffold is in place:

```bash
git clone https://github.com/mishrabishu120-dot/ai-dev-capstone.git
cd ai-dev-capstone
npm install
```

### Environment Variables

Copy the example environment file and fill in required values (when available):

```bash
cp .env.example .env
```

> Never commit `.env` or other files containing secrets. See `.gitignore` for excluded paths.
