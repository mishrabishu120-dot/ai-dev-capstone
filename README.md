# AI Development Capstone

A capstone project demonstrating end-to-end AI-assisted software development — from planning and implementation to version control and deployment workflows.

## Description

This repository documents the development of an AI-powered application built as part of an AI Development Capstone course. The project showcases practical skills in building software with modern AI tooling, managing code with Git and GitHub, and delivering a polished, maintainable codebase using Cursor as the primary development environment.

## Objectives

- Design and implement a functional AI-driven application using Node.js
- Apply AI-assisted development workflows to accelerate coding, debugging, and documentation
- Practice professional version control with Git and collaborative workflows on GitHub
- Structure the project for clarity, maintainability, and future extension
- Document the development process, architecture decisions, and usage instructions

## Tech Stack

| Category | Tools |
|----------|-------|
| **Runtime** | [Node.js](https://nodejs.org/) |
| **Version Control** | [Git](https://git-scm.com/) |
